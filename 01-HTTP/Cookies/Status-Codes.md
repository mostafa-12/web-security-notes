### Categories

- **1xx** → Informational
- **2xx** → Success
- **3xx** → Redirection
- **4xx** → Client Error
- **5xx** → Server Error

### Common Status Codes

- **100 Continue** → Continue sending the request body.
- **200 OK** → Request completed successfully.
- **201 Created** → Resource created successfully.
- **301 Moved Permanently** → Permanent redirect.
- **302 Found** → Temporary redirect.
- **304 Not Modified** → Use cached resource.
- **400 Bad Request** → Invalid request.
- **401 Unauthorized** → Authentication required (WWW-Authenticate header attached with response )
- **403 Forbidden** → Access denied.
- **404 Not Found** → Resource does not exist.
- **405 Method Not Allowed** → HTTP method not allowed.
- **413 Request Entity Too Large** → Request body is too large.
- **414 URI Too Long** → URL is too long.
- **500 Internal Server Error** → Unexpected server-side error.
- **503 Service Unavailable** → Server/application temporarily unavailable.
