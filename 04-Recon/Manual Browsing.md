# Manual Browsing

The first step in mapping a web application is manual browsing.

## Process

- Start from the application's home page.
- Follow every available link.
- Explore all visible functionality.
- Complete all multi-step workflows.

### Examples of Multi-Step Functions

- User Registration
- Login
- Forgot Password
- Password Reset
- Checkout
- Email Verification

## Advantages

- Understand the application's business logic.
- Discover visible pages, features, and user flows.

## Limitations

- Cannot discover hidden or unlinked pages.
- May miss JavaScript-generated endpoints.
- Does not provide complete application coverage.

> Manual browsing is essential, but it should be combined with automated reconnaissance techniques.
