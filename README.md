## About

This repository contains my personal notes while studying Web Security and related topics.

The purpose of these notes is to deepen my understanding by documenting concepts in my own words, not to replace official documentation.

I believe that writing is one of the best ways to learn.

My goal isn't to create something perfect; this is a documentation of my journey, starting in the summer of 2026 and continuing for as long as I keep learning.

I write these notes with one principle in mind: understand how technologies work first, then learn how to break them responsibly.

In the future, whether sooner or later, I will start expanding this repository with every new principle I learn, whether it's related to what came before or something completely new, and I will try to keep it as up-to-date as possible.

I want to share the knowledge I'm learning and help anyone who may find these notes useful in their own learning journey., so I'll make this repository a reference for me and them, and a way to help them. Because the best thing you can do with knowledge is share it. And finally, I wish everyone health and happiness.
