# 10-Targets

## Purpose

توثيق التارجتس (المنصات/المواقع) اللي بنذاكر عليها ريبورتس من الـ bug bounty. كل تارجت له فايل خاص بيه فيه:
- معلومات عامة عن المنصة.
- الـ features/البنية اللي عادةً بتتركز فيها الثغرات.
- لينكات للريبورتس بتاعته (من جوا الريبو أو مصادر خارجية).

> الفايل دا هو المرجع اللي بترجعله لما تلاقي ريبورت جديد يخص تارجت موجود.
