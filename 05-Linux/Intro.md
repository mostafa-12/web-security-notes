# Linux History

## Why Learn the History?

Understanding Linux's history helps explain why Linux is free, open source, and built the way it is today.

And most of Hacking and Dev Tools are mainly working on it, Big Companies and Servers and any modern Tech are driven by Linux, so if we understand it by the way we will understand a big peace of how the Tech world around us is working.

---

## Before Linux: UNIX (1969)

Linux was heavily inspired by **UNIX**, an operating system created in **1969** at **Bell Labs** by:

- Ken Thompson
- Dennis Ritchie

Later, UNIX was rewritten in the **C programming language**, making it faster, understandable, portable across different hardware and leading to its widespread adoption.

but UNIX was limited, it didn't give users freedom, it was limited as source code and hardware that can run it, by the way it wasn't OPEN-SOURCE project 

---

## The GNU Project (1983)

Richard Stallman started the **GNU Project** with the goal of creating a completely **free and open-source UNIX-like operating system**.

GNU successfully developed many essential components such as:

- GCC (Compiler)
- Bash (Shell)
- Core Utilities
- GNU General Public License (GPL)

However, GNU's own kernel (**GNU Hurd**) was never completed in time.

---

## What is a Kernel?

The **Kernel** is the core of an operating system.

It acts as the bridge between **hardware** and **software**, managing:

- CPU
- Memory
- Storage
- Devices
- Processes

Without a kernel, an operating system cannot function.

> Think of the kernel as the manager that coordinates communication between software and the computer's hardware.

---

## The Linux Kernel (1991)

In **1991**, Finnish computer science student **Linus Torvalds** started developing a new kernel as a personal project.

This project became the **Linux Kernel**.

Since GNU already provided most of the operating system tools, combining:

- GNU Tools
- Linux Kernel

created the complete operating system commonly referred to as **Linux** (more accurately, **GNU/Linux**).

## Timeline

| Year | Event |
|------|-------|
| 1969 | UNIX created by Ken Thompson and Dennis Ritchie |
| 1983 | Richard Stallman launches the GNU Project |
| 1991 | Linus Torvalds releases the Linux Kernel |
| Today | GNU tools + Linux kernel power millions of devices worldwide |

---

## Key Takeaways

- Linux was inspired by UNIX.
- GNU created most of the operating system tools.
- GNU lacked a finished kernel.
- Linus Torvalds developed the Linux kernel.
- GNU + Linux Kernel = the modern GNU/Linux operating system.
