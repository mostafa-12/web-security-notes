# ودي أهم قاعدة في Bug Bounty

أنا عايزك تحفظها لأنها هتتكرر في كذا باب بعدين:

> **أي ثغرة بيكون فيها مكونان بيفسروا نفس البيانات بطريقتين مختلفتين، فهي مرشحة جدًا إنها تكون ثغرة أمنية.**

أمثلة:

- **Access Control Bypass:** Nginx يرى `/`، بينما التطبيق يرى `/admin`.
- **HTTP Request Smuggling:** Nginx يحدد نهاية الطلب بطريقة، وGunicorn يحددها بطريقة أخرى.
- **Cache Poisoning:** الـ Cache يعتبر طلبين متماثلين، بينما التطبيق يعتبرهما مختلفين.
- **Path Traversal Bypass:** الـ Proxy يرى المسار بشكل، والتطبيق بعد فك الـ Encoding يراه بشكل آخر.

لاحظ إن **الفكرة واحدة** في كل الأمثلة:

> **مكونان مختلفان → تفسير مختلف لنفس الـ Request → سلوك غير متوقع.**

وده هو السبب الحقيقي اللي PortSwigger حط بسببه اللاب ده، مش علشان يحفظك Header اسمه `X-Original-URL`. لما تفهم المبدأ ده، هتبدأ تشوف إن اللاب بيدرسك طريقة تفكير، مش مجرد Payload.
